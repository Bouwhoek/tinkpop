# AGENTS.md

Voor elke AI-assistent die in deze repo werkt (Claude, GPT/Codex, Gemini, andere).
**De volledige afspraken staan in `CLAUDE.md` en gelden voor iedereen.** Begin bij `docs/README.md`.

Kort:
- De eigenaar codeert niet. Uitleg in gewone taal, in het Nederlands. Site zelf in het Engels.
- Eén onderwerp = één plek. Besluiten: `docs/4-besluiten/besluiten.md`. Open vragen en taken: `docs/4-besluiten/roadmap.md`.
- Legaal by design: elk onderdeel heeft een juridisch blok (`docs/templates/module.md`). Twijfel = niet bouwen, melden.
- Eerst hergebruiken (`docs/2-plan/hergebruik.md`), alleen nette licenties; geen code uit Bambu Studio/OrcaSlicer (AGPL).
- Kleine PR's, één onderdeel per PR, met proeflink. Niets live zetten zonder akkoord van de eigenaar.
- Nooit geheimen in code of chat.
